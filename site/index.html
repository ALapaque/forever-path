Installation

Trois étapes, deux minutes.

  1. 1

    Télécharge

    Récupère le zip de la dernière version sur GitHub (ou bientôt CurseForge / Wago).

  2. 2

    Copie

    Place les dossiers ForeverPath et ForeverPath_Terrain dans _forever_/Interface/AddOns.

  3. 3

    Joue

    Le panneau d'options s'ouvre à la première connexion : coche ce que tu veux. Ensuite, /fp config.
